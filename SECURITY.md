# Security policy

Harness Rotation executes installed coding CLIs against user-selected folders and can connect to self-hosted Coder runners. Treat credential handling, command construction, remote transport, path validation, and Git delivery as security-sensitive areas.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability-reporting flow for this repository when it is available. If private reporting is unavailable, contact the maintainer through the [solhosty GitHub profile](https://github.com/solhosty) with a minimal description and a safe contact method.

Include affected version or commit, reproduction steps, impact, and any suggested mitigation. Do not send credentials, access tokens, private repository URLs, or unredacted logs.

## Supported version

Security fixes are made against the latest commit on main. This is experimental software; no compatibility or response-time guarantee is implied.
